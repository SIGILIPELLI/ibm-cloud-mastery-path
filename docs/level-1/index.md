# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: get comfortable with the `ibmcloud` CLI and IAM, stand up compute,
storage, networking, a database, and a serverless function on the free Lite
tier, and ship a small end-to-end project — with everything torn down
cleanly at the end so nothing keeps billing.

4. [Cloud Object Storage](04-cloud-object-storage.md)
5. [VPC Networking Basics](05-vpc-networking.md)
6. [Cloud Databases](06-cloud-databases.md)
7. [Cloud Functions](07-cloud-functions.md)
8. [Monitoring & Log Analysis](08-monitoring-log-analysis.md)
9. [Schematics (Terraform IaC)](09-schematics-iac.md)
10. [Capstone Project](10-capstone-project.md)

By the end of this level you'll be able to provision and secure core IBM
Cloud resources from the command line, wire them together into a small
working application, observe it, describe it as code, and clean it all up
without leaving anything running on your account.
