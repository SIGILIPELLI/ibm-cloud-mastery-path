# IBM Cloud Mastery Path

A free, structured, module-wise IBM Cloud training program — entry level to master level, with runnable `ibmcloud` CLI commands and config snippets in every module and a hands-on project at the end of each level. Level 1 is built entirely around the free Lite account tier, with explicit teardown steps in the capstone so nothing keeps billing.

**Live site:** https://sigilipelli.github.io/ibm-cloud-mastery-path/

## Contents

- **Level 1 · Entry** — account setup & CLI, IAM, VPC virtual servers, Cloud Object Storage, VPC networking, Cloud Databases, Cloud Functions, monitoring/logging, Schematics (Terraform)
- **Level 2 · Intermediate** — VPC design, load balancing/auto scaling, Kubernetes Service, Code Engine, CI/CD toolchains
- **Level 3 · Advanced** — OpenShift, advanced networking, security/compliance, event-driven architecture, multi-region DR
- **Level 4 · Master** — enterprise IAM & landing zones, hybrid cloud, data/AI services, FinOps, SRE
